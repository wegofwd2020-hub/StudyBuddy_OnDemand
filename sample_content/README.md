# Sample Content

Curated, exported lesson content drawn from `content_store_data/` for use as
reference, research material, and visual / graphical-presentation work.

The actual production content store (`content_store_data/`) is gitignored
because it grows large and is regenerated by the pipeline. This folder is
the deliberate, hand-picked subset that **is** checked in — units we want
to study, share, demo, or use as fixtures for design / a11y / formatting
research.

## Layout

One folder per unit, grouped by curriculum identifier:

```
sample_content/
├── README.md                                    ← this file
└── <curriculum-id>/
    └── <UNIT_ID>_<slugified_topic>/
        ├── <slugified_topic>.md      ← KaTeX-flavoured Markdown
        ├── <slugified_topic>.html    ← KaTeX-rendered standalone HTML
        └── (optional) <slugified_topic>.pdf
```

Curriculum ID matches the production naming (`default-2026-g11-science`,
`default-2026-g8`, etc.). Stripped of the `default-2026-` prefix in this
folder for brevity (`g11-science/`, `g8/`).

## How to add a new sample

The extractor lives at `scripts/extract_unit_to_markdown.ts` and reads
straight from `content_store_data/`.

```bash
# 1. Pick a unit dir from content_store_data/ — for example G11-MATH-001
UNIT_DIR=content_store_data/curricula/default-2026-g11-science/G11-MATH-001
DEST=sample_content/g11-science/G11-MATH-001_Sets_and_Functions

mkdir -p "$DEST"

# 2. Extract Markdown (with quizzes appended)
bun scripts/extract_unit_to_markdown.ts \
  --unit-dir "$UNIT_DIR" \
  --out "$DEST/Sets_and_Functions.md" \
  --include-quizzes

# 3. Render KaTeX-flavoured standalone HTML
pandoc -s --katex \
  --metadata title="Sets and Functions" \
  -o "$DEST/Sets_and_Functions.html" \
  "$DEST/Sets_and_Functions.md"

# 4. (Optional) PDF — needs xelatex
#    sudo apt install texlive-xetex texlive-fonts-recommended
# pandoc --pdf-engine=xelatex --katex \
#   -o "$DEST/Sets_and_Functions.pdf" \
#   "$DEST/Sets_and_Functions.md"
#
# Quick path without LaTeX: open the .html in Chrome → File → Print →
# Save as PDF. KaTeX renders correctly.
```

The script flags:

| Flag | Required | Purpose |
|---|---|---|
| `--unit-dir` | yes | Path to a `content_store_data/curricula/<cid>/<uid>/` dir |
| `--out` | yes | Output `.md` path |
| `--lang` | no (`en`) | Language code — must match a `lesson_<lang>.json` in the unit dir |
| `--include-quizzes` | no | Append all 3 quiz sets with answer keys + explanations |

## What's in each Markdown

Top to bottom:

1. **Lesson overview** — synopsis, key concepts, learning objectives
2. **Tutorial body** — typically 4–6 sections of GFM tables + KaTeX math +
   worked examples + practice questions
3. **Common mistakes** — typical student errors as called out in the source
4. **Quiz sets 1 / 2 / 3** (when `--include-quizzes` is passed) — questions,
   options, correct answer flag, full explanation, difficulty tag

This is exactly what the StudyBuddy pipeline emits — no editorial layer,
no rewriting. Useful as ground truth for renderer / formatting / a11y /
presentation research.
