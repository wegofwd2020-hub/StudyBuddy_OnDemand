### Element data table (the canonical edit surface for downstream chemistry)

`ELEMENTS: Element[]` carries Z=1..36 (periods 1–4) with `{Z, symbol, name, mass, group, period, shells, category, electronegativity, atomicRadiusPm, ionizationEnergyEv}`. **Recommendation for #320:** lift this into `pipeline/visual_templates/elements_data.ts` as the canonical periodic-data source. Future units will need values for periods 5–7 + lanthanides/actinides; growing the table is mechanical.

### What was repetitive (= templatable for #320)

1. **`tileXY(group, period)` layout helper** — maps group/period to (x, y) on the fixed-spacing grid. Used by every periodic-table figure (5 of 9). **Recommendation:** ship as `<PeriodicTableGrid />` shared component with `cellRenderer={(el) => ReactNode}`.

2. **`heatmapTile(el, value, min, max, palette)`** — the new primitive. Three of the four trend SVGs use it identically; the fourth (`trends-arrows-summary`) skips heatmapping but reuses the table grid. **Recommendation:** ship as `<HeatmapTile element value range palette />`.

3. **`makeHeatmapSvg(title, key, palette, ...)`** — the four-figure factory. Three heatmaps generated by ~6 lines each. **Recommendation:** ship as `<PeriodicTrendHeatmap data trendKey palette legend />`.

4. **Mini Bohr-shell-in-a-tile pattern** — `bohr-shells-first-twenty` packs a complete Bohr atom into a 56×56 px tile. Same drawing logic as G11-CHEM-002's full `bohr-shell-model.svg`, just smaller and 20×. **Recommendation:** ship as `<MiniBohrAtom Z size />` — composable into any "many atoms in a grid" diagram.

### What needed human judgment

1. **Grade-level voice on the heatmap captions.** "How hard is it to rip off the outermost electron?" instead of "first ionization energy" lands better at G7. Curator-only G7-friendly translations.

2. **Which trends to include.** The issue listed four (atomic radius / IE / EA / electronegativity) but I shipped three heatmaps + one summary (skipping electron affinity, which has noisy/inconsistent values for G7-level pedagogy). Curator call.

3. **Diagonal staircase placement** in `metal-nonmetal-metalloid-zones`. The boundary between B/Si/As/Te/Po/At is conventional but the *visual* zigzag needed hand-tuning to look like a real staircase — the LLM would draw it as a smooth diagonal line, which is technically incorrect.
